## Prompt 1: Ideation
> I want to participate in this hackathon. Suggest what to build in this. step by step.

*(Sent together with the full EVOX 1.0 challenge description: "Build a Game, Any Concept, Any Type", judged on Innovation, Game Creativity, Approach, Prompting, Engaging Uniqueness.)*

**Result:** The AI proposed "JAILBREAK: Talk Your Way Out", a game about prompting that is itself built by prompting. The player tricks six AI guards, each with a hidden weakness based on a real prompt-injection technique. It runs as a no-API rule engine so it never breaks for judges. The AI also gave a step-by-step build and submission timeline.

## Prompt 2: Build & Deploy
> Please start creating the project and push into github and deploy it.

**Result:** The AI generated the full game (`index.html`, `style.css`, `game.js`):
- CRT hacker-terminal UI with typewriter guard replies and sound effects
- Technique detector (direct ask, instruction override, roleplay, encoding, authority spoof, friendliness, hostility)
- 6 guards with distinct personalities and weaknesses, suspicion meter, lockdown, trust meter, and a boss with 3 adaptive shields
- Star scoring, hints, sector map, saved progress, and "technique unlocked" learning cards
- Pushed to GitHub and deployed on GitHub Pages
